# NEXUS Connect (Тестовая версия)

Клиентское приложение экосистемы **NEXUS AI & VPN** для быстрого и стабильного подключения.

> [!NOTE]
> Это тестовая сборка приложения (Beta). Описание, документация и возможности будут обновляться по мере разработки.

---

## 🚀 Скачивание и запуск

1. Перейдите в раздел [**Releases**](https://github.com/alekseikrasnodar95-sketch/NEXUS_Connect/releases) и скачайте актуальный файл `NEXUSConnect.exe` (или скачайте файл напрямую из файлов репозитория).
2. Запустите `NEXUSConnect.exe` на Windows (установка не требуется — автономный portable-формат).
3. При появлении стандартного окна Windows SmartScreen нажмите *«Подробнее» → «Выполнить в любом случае»*.

---

## 📋 Системные требования

* **ОС:** Windows 10 / Windows 11 (64-bit)
* **Интернет:** Активное сетевое подключение
* **Формат:** Автономный исполняемый файл (`.exe`)
